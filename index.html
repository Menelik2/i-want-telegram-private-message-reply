Mode A • Recommended 👤

Personal Account Auto-Reply (Userbot)

Responds to incoming private messages sent directly to your personal Telegram account (e.g. from friends, clients, leads) while you are away or busy.

1
Visit Telegram Developer Portal:

Open my.telegram.org and sign in with your phone number.

2
Create App:

Click API Development tools, give your app any title (e.g., "MyAIReply"), and get your api_id and api_hash.

3
Run script:

Execute python3 userbot.py. On the first launch, it will ask for your Telegram login code to generate your session file.

Supported via userbot.py
Mode B • BotFather 🤖

Dedicated Bot (@BotFather)

Creates a dedicated bot username (e.g., @MyCustomerSupportBot) via the standard Telegram Bot API for 1-on-1 customer service.

1
Open @BotFather:

Search for @BotFather on Telegram.

2
Create New Bot:

Send /newbot, choose a display name and username ending in bot.

3
Copy Token:

Paste the HTTP API Token into your .env file under TELEGRAM_BOT_TOKEN.

Supported via bot.py

          🐧 Ubuntu / Debian systemd Service (Run on Boot)
        

        

          To ensure your auto-reply userbot restarts automatically if your server reboots, create a systemd service file at /etc/systemd/system/tg-ai-reply.service:
        


        
[Unit]
Description=Telegram Private Message AI Auto-Reply Userbot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/i-want-telegram-private-message-reply
ExecStart=/root/i-want-telegram-private-message-reply/.venv/bin/python3 userbot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
